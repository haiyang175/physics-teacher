# 课程标准框架

本文件是 `physics-teacher` 的课程标准上位约束导航，不是物理知识库，也不替代 `physics-knowledge.md`。它回答：物理教学培养什么、教什么、学生应达到什么表现，以及如何教学和评价。

课程标准引用等级：

- **Level 1**：已核验本地标准文本；可简短引用或指出具体章节，但不得超出核验内容。
- **Level 2**：只有结构化摘要；可说明对应“内容要求 / 学业要求 / 核心素养”等维度，不伪造逐字引文、页码或条款号。
- **Level 3**：无法确认具体条目；只给一般教学建议，并明确“未核验具体课程标准条文”。

用户指定课程标准版本时优先使用指定版本。未指定但学段明确时，使用本文件列出的对应标准；学段无法判断时，先请教师明确，不混用初高中要求。

## 课程标准的十个维度

| 维度 | 在教学设计中的作用 |
|---|---|
| 课程性质 | 确保物理教学兼顾科学性、基础性、实践性与育人价值。 |
| 课程理念 | 指导情境、问题、探究、差异化与评价的总体取向。 |
| 课程目标 | 规定课程学习的总体发展方向。 |
| 核心素养 | 转化为学生行为、学习证据和评价标准，不只作标签。 |
| 内容结构 | 定位主题、模块、学习进阶和跨主题联系。 |
| 内容要求 | 确定本课应教什么，不用它替代物理正确性检查。 |
| 学业要求 / 学业质量 | 确定学生应表现到什么程度，影响任务难度和评价。 |
| 教学建议 | 指导情境、活动、探究、资源与支持方式。 |
| 评价建议 | 建立“要求→表现→证据→标准→反馈”的闭环。 |
| 实验、科学探究与跨学科实践 | 确保实践任务有真实问题、证据、交流和反思。 |

## 对齐原则

1. 课程标准是教学设计和审查的上位约束，不是普通背景知识。
2. 不要求每个任务覆盖全部核心素养；每项任务标明 `primary focus`、`secondary focus`、`non-focus`，只落实当前任务相关的维度。
3. 课程标准要求必须能落到学生表现、学习任务、学习证据与评价标准；无法落地的标签不写。
4. `physics-knowledge.md` 负责物理内容正确性；课程标准 references 负责学习深度、表现要求与教学评价方向。二者不可相互替代。
5. 无法核验的标准信息不得写成“课程标准明确要求”，更不得编造原文、条款号、页码或章节。
