# 输出模板

16 个任务模板（§1–§16）+ 1 个融合方案模板（§17，复合请求用）。**标注「必需」的字段不能省**——省了就等于没完成这项任务。

每个模板末尾都保留三段：`假设` / `信息缺口` / `需教师复核`。这是本 Skill 的固定约定，
不是可选项。

## 教师可调整项

适合的输出应明确指出：哪些内容要按本班学情调整，哪些依赖学校器材，哪些情境可以替换，哪些评价题可以调节难度，以及哪些事实或安全条件需要教师核验。这里的标注用于把输出作为可继续加工的工作底稿，不要求每个模板都增加长篇说明。
