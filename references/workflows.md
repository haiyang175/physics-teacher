# 工作流

16 类任务的分步做法。每一步都给出**质量检查**——不是走过场，是这一节唯一需要认真对待的部分。

§1–§11 是**教学交付物**（教师提需求 → 生成成品）；§12–§16 是**教师专业支持**（教师带作品或困惑来 → 给反馈、思路与提升）。

**学段**：每一步都先确认学段（初中 / 高中）。结构大体通用，但高中在目标表述（核心素养）、数学工具、实验器材、抽象程度上都不同——见 `SKILL.md`「学段适配」。

---

## §1 lesson_plan 教案设计

1. **确认课题与课型** —— 新授课 / 复习课 / 公开课 / 习题课。三者的结构不同，不要套同一个模板。
2. **确认时长与约束** —— 未说明就写「未说明」，不要默认 45 分钟。
   **时长未说明时，教学流程改用占比（%）呈现**，全篇不出现具体分钟数。
3. **教学目标** —— 用可观察的行为动词（说明、区分、计算、设计），不用「掌握」「理解」这类无法检验的词单独成句。
4. **学情起点** —— 教师给了具体表现才写；否则写「未说明」，并给出**可用来了解学情的问题**。
5. **教学重点难点** —— **分开写**。重点是本节课的核心内容，难点是学生认知上真正卡住的地方；两者常常不是同一条。难点要写清**难在哪**（抽象、反直觉、需要多步推理、需要空间想象）。
6. **情境创设** —— 给一个学生能进入的具体情境（生活现象、演示、认知冲突），并说明它**为什么能引出**本节课要解决的问题。不写「创设情境，导入新课」这类空话。
7. **教学流程** —— 表格：时间 | 教师活动 | 学生活动 | 设计意图。时间要和总时长对得上。
8. **关键提问** —— 每节课至少 3 个能暴露学生真实想法的问题。
9. **板书设计** —— 给出板书的**结构与呈现顺序**（主板书 / 副板书的版面安排、哪些内容随讲随写）。板书是学生的笔记骨架，不是把 PPT 标题抄一遍。
10. **评价** —— 课末如何知道学生学会了。
11. **标注缺口** —— 需要课标原文或教材页码的地方，明确写「需以本校在用教材核对」。

**质量检查**
- [ ] 时间校验：时长已知 →「之和＝总时长」；时长未说明 → 流程用占比且「之和＝100%」，且不出现具体分钟数
- [ ] 目标与评价方式对得上（目标说什么，评价就测什么）
- [ ] **重点与难点分开写**，不是同一条
- [ ] 情境创设能自然引出本节课的问题，不是装饰
- [ ] 板书给出了结构和呈现顺序，不是标题罗列
- [ ] 出现「实验」字样就应有器材、变量、安全，否则删掉这个词
- [ ] 没有伪造的课标条款或教材页码

## §2 concept_explanation 概念讲解

沿「现象 → 问题 → 证据 → 模型 → 规律 → 数学表达 → 适用条件 → 反例 → 迁移」推进。

1. **确定学生已有基础** —— 未说明就按初中通用起点，并说明这一假设。
2. **给可观察现象** —— 学生能亲眼看到或亲手做到的，不直接上公式。
3. **提可检验的问题** —— 问题要能用一个实验或一个推理回答。
4. **引入证据** —— 数据、演示或反例。
5. **建立模型** —— 明确研究对象、条件、忽略了什么。
6. **给物理规律** —— 用文字陈述规律本身，说清因果。
7. **给数学表达** —— 公式单独给出，逐个说明每个量的含义、单位、正负号的意义。**不要用公式替代规律**：先有物理规律，再有数学表达。
8. **说明适用条件** —— 这是最常被跳过、也最重要的一步。
9. **给反例与迁移题**。

**质量检查**
- [ ] 结论带条件（「在……条件下，……成立」）
- [ ] **物理规律与数学表达分开给**，不是直接丢公式
- [ ] 没有把某个特例说成普遍规律
- [ ] 易混概念做了显式区分（见 `physics-safety.md`）
- [ ] 教师版与学生版分开：教师版可含教学意图，学生版不含

## §3 diagnosis_report 前置知识诊断

**先查 `physics-knowledge.md`**：那里有前置知识图（哪个概念需要哪些前置）、5 张诊断任务卡（成品级素材）、
以及概念卡的「表征」栏。**有对应条目就用它；没有就说没有**，不要凭空推断前置关系。

1. **先明确要诊断的能力** —— 是概念理解、条件意识，还是变量控制？
2. **设计可区分的任务** —— 正确与错误理解会产生**不同回答**的任务，而不是「会不会」。
3. **给出诊断信号** —— 每种回答对应什么理解状态。
4. **给出追问** —— 学生答对之后追一句，区分「真懂」和「蒙对」。
5. **给出干预** —— 针对每种诊断结果的具体下一步。

**质量检查**
- [ ] 诊断任务能区分不同理解，而不是只分对错
- [ ] 明确写出「不凭单一道题判断学生能力」
- [ ] 没有对具体学生下确定性结论（材料不足时尤其）
- [ ] 干预措施教师当下就能做，不需要额外设备

## §4 misconception_report 错误概念分析

**先查 `physics-knowledge.md`**：那里有 7 张核验过的错误概念卡
（学生的想法 → 科学模型 → 诊断证据 → 诊断任务 → 干预）与 QLM 映射表。
**字段与下面这个模板一一对应**——有就复用，没有再说没有。

1. **复述学生的说法** —— 用学生自己的表述，不要先翻译成正确说法。
2. **指出它错在哪** —— 是概念错、条件漏了，还是变量关系搞反了。
3. **给出正确的物理表述**。
4. **设计能暴露这个错误的诊断问题**。
5. **设计反例或对比实验** —— 让学生自己看到冲突。
6. **给出纠正路径** —— 不是「再讲一遍」，而是让原有想法失效的任务。

**质量检查**
- [ ] 先描述学生想法，再纠正；不是直接讲正确版本
- [ ] 纠正依赖可观察证据，而不是「老师说的」
- [ ] 给出了这个错误概念**为什么会出现**（通常是生活经验或过度推广）
- [ ] 没有把「学生概念错误」和「教师教学策略问题」混为一谈

## §5 experiment_plan 实验设计

**必须包含九项**：器材、变量、步骤、数据记录、实验现象、证据与结论、误差讨论、安全、拓展。

1. **实验目的** —— 一句话，写清要验证或测量什么。
2. **器材** —— 列出并注明规格（量程、分度值）。缺规格会导致实验做不出来。
3. **变量** —— 自变量、因变量、控制变量**分别列出**，并说明如何控制。
4. **步骤** —— 编号，每步是一个可执行动作。
5. **数据记录表** —— 给出列名（含单位和条件列）。**空表也要给**。
6. **实验现象** —— 预期学生看到什么（读数如何变化、有什么可见现象）。现象是学生用来推理的**原始材料**，要写具体，不写「观察实验现象」。
7. **证据与结论** —— **显式写出从数据到结论的推理链**：「若……则说明……」。**不得**写成「做这个实验就可以证明某某规律」；结论必须带条件。
8. **误差与安全** —— 见 `physics-safety.md` 的实验安全清单。
9. **拓展** —— 一个可延伸的问题或变式（改变某个条件会怎样、还能测什么），供学有余力的学生。

**质量检查**
- [ ] 自变量只有一个（除非明确是复合实验）
- [ ] 控制变量写了**怎么控制**，不只是列出名字
- [ ] 数据表有单位，且能直接用来得出结论
- [ ] **给出了「证据 → 结论」的推理链**，而不是断言实验能证明某规律
- [ ] 实验现象写的是可观察的具体表现
- [ ] 量程选择与待测量匹配（如测小灯泡电流不能用 3A 档）
- [ ] 安全事项针对本实验，不是通用套话

## §6 physics_model 物理模型

1. **明确研究对象** —— 研究谁？（不是「这个实验」）
2. **明确系统边界** —— 把什么划进系统、把什么划出去。边界一变，哪些是内力、哪些是外力就变，方程也随之改变。
3. **明确相互作用** —— 它受哪些力/哪些作用，方向如何。
4. **明确状态变量** —— 描述系统状态需要哪些量（位置、速度、温度、电流……），其中哪些可测、哪些只能推算。
5. **明确理想化** —— 做了哪些忽略与假设（忽略空气阻力、视为质点、导线电阻为零……）。**必须在给结论之前写明**，不能事后补。
6. **写出物理规律** —— 遵循哪条定律，为什么适用。
7. **写出数学关系** —— 表达式及每个符号的含义与单位。
8. **说明适用条件** —— 以上理想化在什么范围内成立。
9. **说明模型局限** —— 超出范围会怎样，什么时候彻底不能用。

**质量检查**
- [ ] 研究对象是具体物体或系统，不是泛指的「物体」
- [ ] **系统边界明确**（哪些算系统内、哪些算外部作用）
- [ ] **理想化假设写在结论之前**，不是事后补
- [ ] 状态变量区分了可测与只能推算
- [ ] 受力分析有方向，且与运动状态一致
- [ ] 适用条件具体（不是「条件满足时」）
- [ ] 不补充题干未给的条件

## §7 problem_review_report 题目科学性审查

**门禁：没有完整题干就不做审查。** 明确告知教师缺题干，请他提供。

1. **条件是否完整** —— 求解所需的条件是否都给了。
2. **表述是否有歧义** —— 同一句话能否读出两种意思。
3. **物理是否正确** —— 情境、规律、单位、量级是否合理。
4. **公式是否适用** —— 用到的规律在本情境下成立吗？（例：欧姆定律要求同一段导体、温度基本不变；p=ρgh 只适用于静止液体）
5. **答案是否唯一** —— 有无第二解、有无因取值不同而多解。
6. **干扰项质量**（选择题）—— 每个错误选项是否对应**一种真实的错误理解**？有没有选项其实也成立、或是随便改个数字凑数？
7. **难度与认知层级** —— 标出难度（基础 / 中等 / 较难）与认知层级（记忆 / 理解 / 应用 / 分析）。**不凭感觉**：难度看所需推理步数与条件隐蔽程度，认知层级看学生要做的是回忆、套用还是建模。
8. **是否符合目标年级** —— 是否超纲、是否需要未学的数学工具。
9. **若给了答案**：独立复算核对。**没给答案就说没给**，不要假装复算过。

**质量检查**
- [ ] 每条问题都指向题干中的**具体文字**
- [ ] 区分「题目错误」与「表述可以更好」
- [ ] 选择题检查了干扰项质量
- [ ] 难度/认知层级给了判断依据，不是只贴标签
- [ ] 没有独立复算就说没有
- [ ] 结论可执行（改哪句话，怎么改）

## §8 problem_revision_report 题目改编

**门禁：同 §7，没有完整题干不做改编。**

1. **说明改编目标** —— 降低难度、增加梯度、去掉歧义、换情境。
2. **说明难度来源** —— 原题难在哪（计算量、条件隐蔽、需要多步推理）。
3. **给出改编后的完整题干**。
4. **给出答案与解题过程**。
5. **若做分层设问**：每一问给出答案与设问意图。
6. **说明改编后仍保留了哪些考查点** —— 不能为了降低难度把考点也改没了。

**质量检查**
- [ ] 改编后题目完整、可直接使用
- [ ] 给了答案（不是只给题目）
- [ ] 难度降低有明确理由，不是简单删条件
- [ ] 仍能考查原题的核心概念

## §9 assessment_plan 评价 / 出口检测

**必须包含七项**：学习目标、具体题目、参考答案、评分标准、量规（开放性任务）、反馈、结果使用建议。

1. **学习目标** —— 从教学目标来，可观察可检验。
2. **题目** —— **写出完整题目**，不是「设计几道题」。至少覆盖每个目标。
3. **参考答案** —— 每题都要有。
4. **评分标准** —— 分点给分，写清部分分怎么给。
5. **量规**（开放性任务用）—— 任务是开放的（说理、实验设计、作图、探究方案）时，给**分级量规**：把「完全掌握 / 部分掌握 / 未掌握」各写成**可观察的表现描述**，不是分数区间。
6. **反馈** —— 针对每类典型错误，写出**给学生看的话**（哪里错了、为什么、下一步做什么）。这不是第 7 项的重复：结果使用建议给**教师**，反馈给**学生**。
7. **结果使用建议** —— 学生答错说明什么，下一步怎么教。

**质量检查**
- [ ] 每道题都有答案
- [ ] 每个学习目标都有题目对应
- [ ] 题目条件完整、无歧义、无科学性错误（自查一遍 §7）
- [ ] 评分标准能区分「完全掌握 / 部分掌握 / 未掌握」
- [ ] **开放性任务给了分级量规**，不是只给分数
- [ ] **反馈是面向学生的、可读的话**，不是「注意审题」这类空话
- [ ] 有结果使用建议，不是考完就结束

## §10 homework_plan 分层作业

**必须包含五项**：≥2 个层级、每层适用学生、具体任务、答案/提示/完成标准、分层理由。

1. **分层理由** —— 依据什么分层（基础、速度、错误类型）。教师没给就自己提出并请其确认。
2. **每层适用学生** —— 描述可识别的特征，不是「好学生/差学生」。
3. **每层任务** —— **写出实际题目**。
4. **答案或提示** —— 基础层给提示，提高层给答案或完成标准。
5. **层间关系** —— 说明各层共同的核心目标是什么（不能一层学一个东西）。

**质量检查**
- [ ] 至少两层，每层都有真实题目
- [ ] 每层任务**指向同一个核心概念**，只是支持程度不同
- [ ] 基础层有支架（提示、范例、分解步骤）
- [ ] 不是「A 层做难题、B 层做简单题」这种没有教学逻辑的分法
- [ ] 标注了各层预计用时

## §11 error_analysis_report 匿名错题分析

**门禁：没有学生实际作答就不做错因诊断。**

1. **判断手头有什么**：
   - 有原题 + 学生作答 → 可做**具体错因诊断**
   - 只有原题 → 只能做**题目分析 + 该题常见错误预测**
   - 什么都没有 → 只能给**该类错误的通用成因**，必须明确标注为通用分析

2. **定位错误发生在哪一步** —— 读题、建模、列式、计算、单位。
3. **区分错误类型** —— 概念错 / 条件漏 / 运算错 / 表达不规范。四者的补救方式完全不同。
4. **给出纠正方向** —— 针对错误类型，不是笼统的「多练」。
5. **给出验证是否改正的方法**。

**质量检查**
- [ ] 明确写了本次分析基于什么材料
- [ ] 没有材料就**不假装**做过诊断
- [ ] 区分了概念性错误与运算性错误
- [ ] 建议可执行、可在课堂内完成
- [ ] 全程匿名，不含任何可识别学生的信息

# 教师专业支持（§12–§16）

这一组的输入是**教师自己的作品或困惑**，输出给**教师本人**。与 §1–§11 最大的区别：
§12/§13 的门禁是**教案原文**，§14 的默认交付物是**思路而不是成品**。

---

## §12 lesson_design_review 教案诊断与评估

**门禁：**
- 缺**教学目标**或**教学流程** → 无法诊断。明确说明缺什么，请教师提供。
- 缺器材清单、数据记录表、板书、习题 → **可以诊断**，但必须在「信息缺口」里逐项列明未检查的部分。
- **不凭「教学设计」四个字就开始评。**

1. **先说清本次基于什么材料** —— 完整教案 / 只有流程 / 只有目标。
2. **目标是否可检验** —— 还是「掌握」「了解」这类无法观察的词。
3. **目标—活动—评价是否对齐** —— 目标说什么，活动就做什么，评价就测什么。**三者错位是新手教案最常见的问题**。
4. **时间是否可行** —— 各环节相加是否超时；有没有某个环节明显不够用。
5. **学生活动是否足够** —— 还是全程教师讲、学生听。
6. **难点是否被真正处理** —— 还是只在目标里提了一句，流程里没有对应环节。
7. **物理内容是否正确** —— 转 §7 的检查项与 `physics-safety.md`。
8. **实验/探究是否完整** —— 器材、变量、证据→结论、安全（转 §5）。
9. **探究的结论是否由设计的数据支持** —— **伪探究检测**：教案里预写的结论，用这个实验步骤真做得出来吗？
   做不出来，学生测到的数据就和结论打架。**这是新手教案的高频问题，且比「步骤写漏了」更致命。**
10. **情境是否与内容相关** —— 还是只为了热闹。
11. **评价能否区分掌握程度** —— 还是只有「对/错」。

**输出**：逐项表（结论 + **依据指向教案中的具体文字**）+ 改进建议，分「**必须改**」与「**建议改**」两档。

**严重度分级**
- **物理科学性错误 → 一律进「必须改」，排在输出最前、单独成条，并写明「为什么错」与「学生会带到哪里去」。**
  它和「时间安排偏紧」不是一个量级，**不要并列呈现**。
- 目标不可检验、伪探究、难点无对应环节 → 必须改。
- 时间偏紧、器材未列出、情境关联弱 → 建议改。
- **纯粹的教学风格差异 → 明确标为「风格偏好，不是问题」**，不要混进建议里。

**质量检查**
- [ ] 每条问题都指向教案中的**具体环节或原话**
- [ ] **物理科学性错误单列，且排在「必须改」的最前**
- [ ] 检查了「探究结论是否由设计的数据支持」（伪探究）
- [ ] 区分「设计问题」与「风格偏好」——**不要把自己的教学习惯当成标准**
- [ ] **没有为了显得认真而编造问题**——没发现问题的检查项写「未发现问题」
- [ ] 建议可执行（改哪个环节、怎么改）
- [ ] **不替教师重写整份教案**——那是 §13 的事；诊断只指问题
- [ ] 材料不足时按门禁阈值处理（缺目标或流程才停止诊断）

## §13 lesson_plan_revision 教案修订

**门禁：同 §12，没有教案原文不做修订。**

这是教师最常提的需求（「帮我改一下这个教案」），也是最容易做坏的一个——
**改着改着就把教师的设计改没了**。

1. **说明修订目标** —— 压缩时间 / 降低难度 / 增加学生活动 / 换情境 / 适配学情 / 修正科学性错误。
2. **说明原教案的问题在哪** —— 承接 §12 的诊断结论，不重复整份诊断。
3. **给出修订后的完整教案** —— 可直接使用，不是「改这几处」的说明。
4. **逐条列出改了什么、为什么** —— 每条改动都要有理由。
5. **说明保留了哪些原设计** —— **教师原教案里的合理设计不能被改掉**。
6. **说明修订后仍存在的问题** —— 不要假装改完就没有缺点了。

**质量检查**
- [ ] 修订后的教案完整、可直接使用
- [ ] 每处改动都给了理由，不是凭偏好
- [ ] **明确列出了保留的原设计**
- [ ] 改动清单能与原教案逐条对照
- [ ] 没有为了解决一个问题而引入科学性错误（改完再过一遍 `physics-safety.md`）

## §14 design_coaching 设计教练

**这一节的全部价值在于克制。** 教师卡住时，默认交付物是**思路，不是成品**。

1. **先弄清卡在哪** —— 是目标不清、环节接不上、难点不知道怎么处理，还是不知道学生会在哪里出错？**追问一句比直接给方案有用**。
2. **判断约束够不够** —— 如果方向取决于班额、器材、课时这类条件而教师没说，**先反问，暂不给方向**（一轮就够）。
   约束已经足够时，直接给方向，不要为了显得严谨而多问一轮。
3. **给 2–3 个方向，不是 1 个答案** —— 每个方向说明「怎么做」+「**代价或风险是什么**」。
4. **给一个追问** —— 让教师自己往下想。例如「你这节课最希望学生带走的一句话是什么？」
5. **教师选定方向后，仍在方案层面细化** —— 细化到环节、学生任务、组织方式；
   **仍不给可以照抄的文本**。直到教师明确说「帮我写出来」才转 §1。

**「怎么做」的粒度**：给到**教学决策**为止——用什么情境、学生做什么任务、怎么组织、可能出什么乱子。
**不给可以照抄的文本**——导入语、板书全文、习题、逐字讲稿。越界就不是教练而是代笔了。

**明确禁止**：教师只要思路，你却把整份教案写完了。那会让教师拿不到成长，也违背这个能力的初衷。

**质量检查**
- [ ] 给的是**方向与取舍**，不是成品
- [ ] 每个方向都写了代价，不是三个都说好
- [ ] 有一个能让教师自己想下去的追问
- [ ] **没有给可以照抄的文本**（导入语、板书全文、习题、逐字讲稿）
- [ ] 约束不足时先反问了一轮，没有硬猜
- [ ] **没有在教师只要思路时把教案写完**
- [ ] 教师真要成品时，明确转 §1，并说明「那我按教案给你出完整版」

## §15 content_deepening 学科内容拓展

面向**教师本人**的学科深度——不是讲给学生，是给教师补底气。
教师可能非物理专业出身、或多年没教某个模块，需要知道「这块内容到底是什么」。

1. **确认概念与学段** —— 是初中的「浮力」还是高中的「电场」？
2. **讲清这个概念在物理学里到底是什么** —— 本质，不只是教材表述。
3. **说明教材为什么这样处理** —— 简化了什么、为什么在这个学段必须这样简化。
4. **指出更完整的理解** —— 用教师能懂的语言给出更高层的图景，不堆砌大学教材。
5. **指出这节课的重难点与突破手段** —— 教师问的不只是「这块内容是什么」，还有「**这块内容怎么教**」。
   要写清：对学生难在哪（抽象 / 反直觉 / 需要哪个前置知识）、通常卡在哪一步、有哪些突破手段。
6. **划定学段边界** —— **哪些不要讲给学生、讲了会造成什么后果**（超出认知、与后续学习冲突）。
7. **给出可以回答学生「为什么」的深度版本** —— 教师最需要的是被学生追问时不慌。

**质量检查**
- [ ] **明确标注了哪些内容不要直接讲给学生**
- [ ] 讲了教材为什么这样简化
- [ ] 没有用超出教师需要的大学内容堆砌
- [ ] 不伪造具体文献、页码、实验数据
- [ ] 给了一个教师可以直接用来回应学生追问的表述

## §16 pedagogy_theory 教育理论

**这是全库最容易编造的一节。** 理论内容必须比物理内容更保守。

1. **确认教师问的是哪个理论或概念** —— 最近发展区、探究式学习、教学原则、布鲁姆分类……
2. **讲清核心主张** —— 一句话能说清的版本，不是名词堆砌。
3. **说明它解决什么教学问题** —— 理论是用来解决什么的，不是用来背的。
4. **落到这节课的具体建议** —— **没有这一步就是空谈**。教师问「最近发展区」，
   不是想听定义，是想知道「我这节课该怎么用」。
   **教师没给具体课时，先问一句是哪个课**，或退一步给出「怎么判断用对了」的标准；
   不要硬编一节课出来。
5. **说明适用边界与争议** —— 它不是什么都能解释；有哪些常见误用。
   **不清楚该理论的争议时就不写这一条**，或写「这一条我不确定」。
   为了填满栏目而编一个争议，比空着更糟。
6. **不编造** —— 不编文献页码、不编具体研究数据、不把某个理论说成学界共识。
   **人名与出处同样适用**：不确定某个说法是谁提出的，就只讲主张、不提人名。
   说「有研究提出」比说错一个人名安全得多——**宁可不提，不可说错**。

**面向新兴教师**：术语第一次出现时给一句话解释。新兴教师通常没系统学过教学法，
直接抛「支架式教学」「元认知」而不解释，等于没说。

**质量检查**
- [ ] 讲清了核心主张，不是名词堆砌
- [ ] **落到了本节课的具体教学建议**（教师没给课时时，给了判断标准或先问了课）
- [ ] 说明了适用边界；**不清楚的争议没有硬编**
- [ ] **没有编造文献、页码、研究者言论或研究数据**
- [ ] **不确定的提出者或出处没有硬安人名**——宁可不提，不可说错
- [ ] 区分了「理论主张」与「教学常识」，没有把前者说成后者
- [ ] 首次出现的术语给了解释
