## 一、易混概念 —— 必须显式区分

写这些概念时，**不能互换使用**，也不能用「差不多」「类似」带过。
**先判断学段，用对应那一段。**

### 初中

| 概念 A | 概念 B | 区别要点 |
|---|---|---|
| **压力** | **压强** | 压力是力（N），有方向；压强是压力作用效果（Pa），由压力和受力面积共同决定。**「压力大」不等于「压强大」**——面积不同时结论会反过来。 |
| **质量** | **重力** | 质量是物质的量（kg），不随位置变化；重力是地球的吸引（N），随 g 变化。G = mg 是**关系式**，不是「质量就是重力」。 |
| **速度** | **力** | 速度描述运动快慢，力改变运动状态。**「力越大速度越大」是错的**——力决定的是加速度，不是速度本身。 |
| **功** | **功率** | 功是能量转化的量度（J）；功率是做功快慢（W）。做功多不代表做功快。 |
| **热量** | **温度** | 热量是热传递中转移的能量（J）；温度是状态量（℃）。**「物体含有多少热量」是错的**。 |
| **音调** | **响度** | 音调由频率决定，响度由振幅和距离决定。**两个量互相独立**——音调高不代表响度大。 |
| **电阻** | **欧姆定律** | 电阻是导体本身的性质；欧姆定律是 I、U、R 三者的关系。**「电阻越大电流一定越小」错**——必须在电压不变的前提下才成立。 |
| **漂浮** | **悬浮** | 都满足 F浮 = G，但漂浮时 V排 < V物（部分浸入），悬浮时 V排 = V物（全部浸入）。 |
| **电流做功** | **电流被消耗** | **电流不会「被消耗」**——串联电路中各处电流相等，被转化的是电能。 |

### 高中

| 概念 A | 概念 B | 区别要点 |
|---|---|---|
| **速度** | **速率** | 速度是矢量（有方向），速率是速度的大小。**匀速圆周运动速率不变、速度时刻在变**。 |
| **速度** | **加速度** | 速度描述运动快慢；加速度描述速度**变化**的快慢。**v=0 时 a 可以很大**（竖直上抛最高点、弹簧振子最大位移处）；**v 很大时 a 可以为零**（高速匀速）。 |
| **加速度** | **速度变化量 Δv** | a = Δv/Δt，**不是 Δv**。Δv 大不代表 a 大，还要看所用时间。 |
| **位移** | **路程** | 位移是矢量、由初末位置决定；路程是标量、由实际路径决定。只有单向直线运动时两者大小相等。 |
| **功** | **功率** | 功是能量转化的量度（J）；功率是做功快慢（W）。高中还要注意：功**有正负**（看力与位移的夹角），功率分**平均功率与瞬时功率**。 |
| **动能** | **动量** | 动能 Ek=mv²/2 是**标量**；动量 p=mv 是**矢量**。动能变化由**合力做的功**决定；动量变化由**合力的冲量**决定。 |
| **动量** | **冲量** | 动量是**状态量**（某时刻）；冲量是**过程量**（一段时间）。 |
| **电场强度 E** | **电势 φ** | E=F/q 描述电场**力**的性质（矢量）；φ=Ep/q 描述电场**能**的性质（标量）。**两者没有必然的大小关系**——负点电荷附近 E 很大而 φ 很低；匀强电场中 E 处处相同，但 φ 沿电场线降低。 |
| **电场强度 E** | **电势差 U** | U=Ed **只适用于匀强电场**，且 d 必须是**沿电场方向**的距离。 |
| **电势 φ** | **电势能 Ep** | 电势由电场本身决定，**与试探电荷无关**；电势能属于电荷与电场组成的系统，随试探电荷而变。 |
| **电动势 E** | **路端电压 U** | 电动势是电源自身的性质；路端电压 U = E − Ir，随电流变化。**开路时路端电压等于电动势**。 |
| **磁通量 Φ** | **变化率 ΔΦ/Δt** | 感应电动势由**变化率**决定，**不由 Φ 本身决定**。Φ 很大但不变时，感应电动势为零。 |
| **磁感应强度 B** | **磁通量 Φ** | Φ = BS，其中 S 为**垂直于 B** 的有效面积。 |
| **安培力** | **洛伦兹力** | 安培力是磁场对**通电导线**的力；洛伦兹力是磁场对**运动电荷**的力。判断洛伦兹力方向用左手定则，**注意电荷正负**。 |
| **左手定则** | **右手定则** | 左手判断**力**（安培力、洛伦兹力）；右手判断**感应电流方向**。判断感应电流也可用楞次定律。 |
| **温度** | **内能** | 温度是分子**平均动能**的标志；内能还包括分子势能，与分子数、体积都有关。**温度高，内能不一定大**。 |
| **热量** | **内能** | 热量是**过程量**；内能是**状态量**。不能说「物体含有多少热量」。 |
| **振动图象** | **波的图象** | 振动图象是**一个质点**随**时间**的变化；波的图象是**某一时刻**所有质点的分布。形状可能相同，含义完全不同——**高频易混点**。 |
| **干涉** | **衍射** | 干涉是两列（或多列）**相干波**叠加；衍射是波**绕过障碍物**或通过狭缝后扩展。 |

## 二、危险表述 —— 不得写出

以下说法在物理上是错的。**不得以任何形式（包括「通常」「一般」）出现在输出中。**

### 初中

| 错误表述 | 为什么错 | 正确说法 |
|---|---|---|
| 物体越重，受到的浮力越大 | 浮力只由液体密度和排开液体的体积决定，与物体自身重力无关 | 浮力 F浮 = ρ液 g V排 |
| 同一个物体在液体中越深，浮力越大 | 完全浸没后 V排 不再变化，浮力不变 | 浸没后浮力与深度无关（深度影响的是液体压强） |
| 物体沉底就没有浮力 | 沉底时仍受浮力，只是 F浮 + N = G | 沉底时受浮力，同时受容器底支持力 |
| 压力一定等于重力 | 压力取决于接触面和受力状态，与重力无必然相等关系 | 需先明确研究对象与受力面 |
| 力越大速度越大 | 力改变的是运动状态（产生加速度），不是速度大小本身 | 合力为零时物体可做匀速直线运动 |
| 物体运动一定受到力 | 力不是维持运动的原因 | 力是改变运动状态的原因 |
| 电阻越大，电流一定越小 | 需在电压不变的前提下才成立 | I = U/R，三者需同时考虑 |
| 音调越高，响度越大 | 两者由不同物理量决定，互相独立 | 音调由频率决定，响度由振幅决定 |
| 有温度就一定有热量 | 热量是过程量，不是状态量 | 只能说「吸收/放出了多少热量」 |
| 功率越大，做功越多 | 功率是做功快慢，还要看时间 | W = Pt |
| 机械效率可以大于 1 | 有用功不可能大于总功 | η = W有用 / W总 ≤ 1 |
| 物体温度越高，含有的热量越多 | 热量不是「含有」的量 | 说「内能」而非「热量」 |

### 高中

| 错误表述 | 为什么错 | 正确说法 |
|---|---|---|
| 物体速度为零，加速度一定为零 | 加速度由合力决定，与速度无关 | 竖直上抛最高点、弹簧振子最大位移处：v=0 但 a≠0 |
| 速度越大，加速度一定越大 | 加速度是速度的**变化率** | 高速匀速飞行：v 很大，a=0 |
| 物体受力越大，速度就越大 | 力决定的是加速度 | F=ma；速度还取决于初速度与加速时间 |
| 摩擦力一定是阻力 | 摩擦力阻碍的是**相对运动（趋势）**，不是运动本身 | 静摩擦可使物体随传送带一起加速——此时摩擦力是**动力** |
| 作用力与反作用力可以相互抵消 | 它们作用在**两个不同物体**上 | 只有作用在同一物体上的力才能求合力 |
| 电场强度大的地方电势一定高 | E 与 φ 描述电场的不同性质，无必然大小关系 | E 大处 φ 可以很低（负点电荷附近） |
| 电势为零的地方电场强度一定为零 | φ=0 的参考点是人选的，与 E 无关 | 等量异种点电荷连线中点：φ=0，但 E≠0 |
| 磁通量越大，感应电动势越大 | 由**变化率**决定，与 Φ 本身无关 | E = nΔΦ/Δt |
| 磁通量为零时感应电动势一定为零 | Φ=0 的瞬间变化率可能**最大** | 线圈平面与 B 平行时 Φ=0，但正在转动时 ΔΦ/Δt 最大 |
| 通电导线在磁场中一定受安培力 | 导线与 B 平行时受力为零 | F = BIL（要求 B⊥I）；平行时 F=0 |
| 感应电流的磁场总是与原磁场方向相反 | 楞次定律说的是**阻碍变化**，不是「反向」 | 原磁通**增大**时反向，**减小**时同向 |
| 电场线就是电荷运动的轨迹 | 电场线描述电场，不是轨迹 | 只有初速度为零（或沿电场线方向）且只受电场力时两者才重合 |
| 电流在电阻上被消耗掉了 | 电荷量不减少，转化的是电能 | 串联电路中各处电流相等 |
| 卫星轨道半径越大，运行速度越大 | 由 GMm/r² = mv²/r 得 v=√(GM/r) | 半径越大，线速度**越小**、周期越长（「高轨低速」） |

**另外**：
- 不得伪造课程标准条款、教材页码、版本或文献引用。需要时请教师提供，或以合法版本核对。
- 不得把「某次实验的结果」说成「证明了某理论」——初中实验是**验证性/探究性**的，结论要带条件。
- 不得给出未经核验的数据（如「某地重力加速度为 9.8」以外的具体数值）当作事实。

## 三、实验安全清单

每个实验方案都必须检查。**安全事项要针对本实验，不是通用套话。**

### 通用
- [ ] 器材完好、无破损（玻璃器皿尤其）
- [ ] 器材规格与待测量匹配（量程、分度值）
- [ ] 学生知道异常情况的处理方式（如断电、灭火）

### 电学实验
- [ ] **电流表串联、电压表并联**，接线正确
- [ ] **量程选择**：先估算，优先大档试触。测小灯泡电流不能用 3A 档
- [ ] **电源电压不超过用电器额定值**（小灯泡额定 6V 就不能接 12V）
- [ ] 滑动变阻器**接线柱接法正确**（一上一下），闭合开关前置于阻值最大端
- [ ] 连接电路时**开关断开**
- [ ] 不短路电源；不用湿手操作
- [ ] 通电时间不宜过长（灯泡发热、电阻发热）

### 力学实验
- [ ] 重物与支架稳固，防止掉落砸伤
- [ ] 弹簧测力计**不超过量程**，使用前校零
- [ ] 斜面/小车实验注意滑轮与绳子夹手
- [ ] 摩擦力实验注意摩擦生热

### 用温度计 / 热学
- [ ] 温度计玻璃泡**不接触容器底和壁**
- [ ] 读数时**不离开被测液体**（视实验要求）
- [ ] 使用酒精灯：用火柴点燃，用灯帽盖灭，**不得用嘴吹**
- [ ] 加热的液体与器皿不得立即用手取用

### 光学实验
- [ ] **激光不得直视**，也不得照射他人眼睛
- [ ] 平面镜/透镜注意边缘划伤

### 声学实验
- [ ] 音叉等注意音量，避免长时间近距离
- [ ] 弦乐器注意断弦伤手

### 高中专项

- [ ] **打点计时器**：电磁式为 4–6 V **交流**，电火花式为 **220 V 交流**——用错电源会损坏或触电；纸带与复写纸安装到位，防止卡纸
- [ ] **电容器实验后必须放电**：大电容储能可观，直接用手接触引脚有放电风险
- [ ] **高压静电实验**（感应起电机、范德格拉夫起电机）：操作前先放电，学生不得自行接触
- [ ] **多用电表**：测电阻前先断开被测电路、换挡后重新调零；不得用电表的电流挡去测电压
- [ ] **示波器 / 信号发生器**：按说明书接线，亮度不宜过高、光点不宜长时间停在同一点（会烧屏）
- [ ] **分压 / 限流接法**：滑动变阻器接法错误会导致短路或电压无法调节，接线前先确认接法
- [ ] **油膜法测分子直径**：油酸酒精溶液避免接触皮肤与眼睛，实验在通风处进行
- [ ] **放射性演示（选修）**：只用长柄镊子操作，不得用手直接接触放射源；用后放回铅罐

## 四、常见学生错误概念（供诊断与纠正参考）

### 初中

**已移入 `physics-knowledge.md`。** 那里是项目人工核验的数据——7 张错误概念卡（含科学模型 / 诊断证据 / 诊断任务 / 干预）、

字段比这里原来那张手写表完整得多。

> **做初中学情诊断或错误概念分析时，读 `physics-knowledge.md`，不要用本文件。**

<!-- 以下手写表已停用，保留仅为对照；新增条目一律进 physics-knowledge.md -->

| 主题 | 学生常见想法 | 纠正方向 |
|---|---|---|
| 力与运动 | 物体要保持运动，必须一直受力 | 用冰面滑行、气垫导轨类对比，让「撤去力后继续运动」变得可见 |
| 压力与压强 | 压力大压强就大 | 同一压力作用在海绵大小面上，先控制变量再比较 |
| 浮力 | 浮力与物体重力有关 | 同一物体换不同液体 / 不同物体排开同体积液体的对比 |
| 浮力 | 越深浮力越大 | 完全浸没后继续下沉，读数不变 |
| 电流 | 电流会被用电器消耗 | 串联电路中各处电流相等的演示 |
| 电阻 | 电阻越大电流越小 | 强调需控制电压不变 |
| 功率 | 功率大做功多 | 引入时间变量做对比 |
| 音调与响度 | 音调高就是响度大 | 分开改变频率与振幅，听感对比 |

### 高中

| 主题 | 学生常见想法 | 纠正方向 |
|---|---|---|
| 运动学 | 速度大加速度就大 | 对比「高速匀速飞行」（v 大 a=0）与「起步瞬间」（v 小 a 大） |
| 运动学 | 位移大速度就大 | 位移是过程结果，用 v-t 图面积说明 |
| 牛顿定律 | 力是维持运动的原因（初中遗留） | 气垫导轨 / 冰面演示：撤去拉力后仍匀速 |
| 摩擦力 | 摩擦力一定阻碍运动 | 传送带带动物块的例子——摩擦力是动力 |
| 超重失重 | 超重就是重力变大了 | 电梯中体重计读数：**视重**变化，重力没变 |
| 圆周运动 | 向心力是「额外的一个力」 | 受力分析说明向心力是**合力的效果**，不是新的力 |
| 万有引力 | 轨道越高，卫星速度越大 | 由 v=√(GM/r) 定量说明「高轨低速」 |
| 电场 | 电场线是真实存在的线 | 电场线是**描述工具**，不是实物 |
| 电场 | E 大处 φ 一定高 | 负点电荷附近反例；强调二者描述不同性质 |
| 电路 | 电流在电阻上被消耗 | 串联电路各处电流相等的演示 |
| 电磁感应 | 磁通量大就有感应电动势 | 强调**变化率**；演示 Φ=0 但正在转动时仍有电动势 |
| 动量 | 动量大小相同，动能就相同 | 举 p 相同但 m 不同、Ek 不同的例子（Ek = p²/2m） |
| 热学 | 温度高内能就大 | 一杯热水与一桶同温水的对比（分子数不同） |
