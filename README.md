# Physics Teacher

面向中国初中与高中物理教师的备课、教研与专业发展助手。

这是一个**自包含的提示词型 Skill**：不依赖外部程序、数据库或网络服务。将本目录作为 Skill 加载后，教师可以直接用自然语言提出需求，Skill 会识别任务类型、检查材料是否完整，并按需要组织诊断、建模、实验、评价和教案设计等工作。

## 能做什么

### 教学交付物

- 教案、公开课、复习课与新授课设计
- 物理概念讲解与前置知识诊断
- 学生错误概念分析与纠正路径
- 实验方案、变量设计、误差与安全检查
- 物理模型分析与适用条件说明
- 题目科学性审查与题目改编
- 形成性评价、出口检测与评分标准
- 分层作业与匿名错题分析

### 教师专业支持

- 教案诊断与评课
- 教案修订
- 教学设计教练：提供方向与决策支持，不直接替教师写成品
- 高中物理内容拓展
- 教育理论的教学应用与边界说明

## 核心特点

- **覆盖初高中**：初中侧重现象、定性理解和控制变量；高中侧重定量关系、模型、图像和数学工具。
- **支持复合请求**：例如“设计一节浮力公开课，包含实验，并考虑学生常见错误”，会自动展开依赖任务并融合成一份方案。
- **材料门禁**：没有题干不审题，没有学生作答不做针对性错因诊断，没有教案原文不直接修订。
- **物理 QA + Pedagogy QA**：同时检查物理正确性、适用条件、教学可实施性、时间与器材约束。
- **防止过度生成**：支撑任务只输出关键摘要；教师只要思路时，不强行产出完整教案。
- **明确边界**：不伪造教材版本、课程标准、文献出处或专家审核结论；不处理未匿名化的个人信息。

## 使用方式

将本目录作为 `physics-teacher` Skill 加载，然后直接用自然语言提问即可。例如：

```text
请设计一节八年级“浮力”公开课，要有实验，并考虑学生常见错误概念。
```

```text
请帮我诊断下面这份高中物理教案，重点检查物理错误和教学流程是否可实施：
（粘贴教学目标与教学流程）
```

```text
学生认为“物体受到浮力就一定漂浮”，请分析这个错误概念并设计纠正路径。
```

为了获得针对性结果，建议尽量提供：学段、年级、主题、学生表现、课时长度、教学目标、已有教案或完整题干。信息不足时，Skill 会先指出缺口，并区分“通用分析”和“针对该班/该生的判断”。

## 工作方式

Skill 的基本流程是：

1. 识别任务类型并提取约束
2. 检查输入材料是否足够
3. 对复合请求按依赖图展开并排序
4. 查阅对应工作流、知识库、安全清单与输出模板
5. 生成教学交付物或专业支持结果
6. 进行 Physics QA 与 Pedagogy QA
7. 标注假设、信息缺口和需要教师复核的部分

## 评测

`evals/` 是本 Skill 的行为回归集，不是可执行代码。评测重点包括：

- 材料不足时是否明确说明限制
- 复合请求是否正确编排并传递前序结论
- 教练模式是否避免直接交付完整成品
- 理论、人名、出处和争议是否避免编造
- 是否能识别教案中的物理错误
- 是否区分初中与高中学段边界
- 是否正确使用知识库，且在没有条目时不擅自编造

完整说明见 [`evals/README.md`](evals/README.md)，任务规则见 [`SKILL.md`](SKILL.md)。

## 适用范围与限制

本 Skill 适合用于备课、教研、教学设计检查和教师专业成长支持。它提供的是结构化启发式分析，不替代教研组、学科专家或学校安全制度的审核。涉及实验、高压、电学、热学、光学和放射性相关内容时，仍应以学校器材说明、实验室制度和教师现场判断为准。
