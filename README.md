# Physics Teacher

面向中国初中与高中物理教师的可复用 Codex Skill，用于备课、教研、教学设计、学情诊断、实验设计与评价审查。

这是一个**自包含的提示词型 Skill**，不是 Agent 或独立应用：不依赖运行时、数据库、网络服务或外部 API。加载本目录后，教师可以直接用自然语言提出需求，Skill 会识别任务、检查材料门禁，并按需组织诊断、建模、实验、评价和教案设计。

## 快速开始

将本目录作为 `physics-teacher` Skill 加载，然后直接提问：

```text
请设计一节八年级“浮力”公开课，要有实验，并考虑学生常见错误概念。
```

为了得到可执行的结果，尽量提供：学段、年级、主题、课时、器材、学生表现、教学目标、已有教案或完整题干。材料不足时，Skill 会明确指出缺口，不替教师虚构条件。

## 能做什么

### 教学交付物

- 教案、公开课、复习课与新授课设计
- 物理概念讲解与前置知识诊断
- 学生错误概念分析与纠正路径
- 实验方案、变量设计、误差与安全检查
- 物理模型分析与适用条件说明
- 题目科学性审查与题目改编
- 形成性评价、出口检测与评分标准
- 分层作业与匿名错题分析

### 教师专业支持

- 教案诊断与评课
- 教案修订
- 教学设计教练：提供方向与决策支持，不直接替教师写成品
- 高中物理内容拓展
- 教育理论的教学应用与边界说明

## 核心特点

- **面向初高中但范围诚实**：工作流覆盖初高中；结构化知识库当前以初中为主，高中主要依靠物理 QA、安全边界和部分内容拓展，不等同于完整高中知识库。
- **支持复合请求**：例如“设计一节浮力公开课，包含实验，并考虑学生常见错误”，会自动展开依赖任务并融合成一份方案。
- **材料门禁**：没有完整题干不具体审题，没有具体错误证据不做个体错因归因，没有教案原文不直接修订。
- **物理 QA + Pedagogy QA**：同时检查物理正确性、适用条件、教学可实施性、时间与器材约束。
- **防止过度生成**：支撑任务只输出关键摘要；教师只要思路时，不强行产出完整教案。
- **明确边界**：不伪造教材版本、课程标准、文献出处或专家审核结论；不处理未匿名化的个人信息。
- **课标版本边界**：当前本地义务教育来源为“2022 年版 2025 年修订”，不等同于纯 2022 年版原文；未指定版本时输出实际采用的来源标签，指定纯 2022 年版但无对应核验原文时不提供逐条引用、页码或条款号。

```text
请帮我诊断下面这份高中物理教案，重点检查物理错误和教学流程是否可实施：
（粘贴教学目标与教学流程）
```

```text
学生认为“物体受到浮力就一定漂浮”，请分析这个错误概念并设计纠正路径。
```

## 工作方式

Skill 的基本流程是：

1. 识别任务类型并提取约束
2. 检查输入材料是否足够
3. 对复合请求按依赖图展开并排序
4. 查阅对应工作流、知识库、安全清单与输出模板
5. 生成教学交付物或专业支持结果
6. 进行 Physics QA 与 Pedagogy QA
7. 标注假设、信息缺口和需要教师复核的部分

## 任务范围

### 主要任务

- 教案设计、评审与修订
- 概念讲解、前置知识诊断与错误概念分析
- 实验方案、控制变量、误差与安全检查
- 物理模型分析、题目审查与题目改编
- 形成性评价、出口检测、分层作业与匿名错题分析
- 教学设计咨询、教育理论应用和高中物理内容拓展

### 核心约束

- **证据优先**：没有完整题干不具体审题；没有具体学生错误证据不做个体错因归因。
- **条件诚实**：不默认器材、课时、班级、学情或学校资源；未知条件标为“待教师确认”。
- **课程标准对齐**：课程标准要求必须进入学生表现、学习任务、学习证据和评价，不机械罗列核心素养。
- **物理正确性**：结论写明适用条件；实验数据不被外推为无条件规律。
- **范围诚实**：面向初高中教师，但结构化物理知识库当前以初中为主，高中不等同于完整知识库。

## 课程标准版本边界

当前本地义务教育课程标准来源标记为 **“2022 年版 2025 年修订”**，不等同于经过核验的纯“2022 年版”原文。

- 未指定版本：输出会标明实际采用的来源标签。
- 指定“2022 年版”：可做共同结构的一般性对齐，但不伪造纯 2022 年版的原文、页码或条款号。
- 指定“2022 年版 2025 年修订”：可依据当前来源进行对齐，精确引用不超出已核验文本。

## 评测与质量控制

`evals/` 是本 Skill 的行为回归集，不是可执行代码。评测重点包括：

- 材料不足时是否明确说明限制
- 复合请求是否正确编排并传递前序结论
- 教练模式是否避免直接交付完整成品
- 理论、人名、出处和争议是否避免编造
- 是否能识别教案中的物理错误
- 是否区分初中与高中学段边界
- 是否正确使用知识库，且在没有条目时不擅自编造
- 课程标准要求是否真正进入目标、活动、学习证据与评价

完整说明见 [`evals/README.md`](evals/README.md)，任务规则见 [`SKILL.md`](SKILL.md)。当前仓库保留 16 个 workflow、17 个行为评测用例，以及课程标准对齐和质量评测。

## 适用范围与限制

本 Skill 适合用于备课、教研、教学设计检查和教师专业成长支持。它提供的是结构化启发式分析，不替代教研组、学科专家或学校安全制度的审核。涉及实验、高压、电学、热学、光学和放射性相关内容时，仍应以学校器材说明、实验室制度和教师现场判断为准。
